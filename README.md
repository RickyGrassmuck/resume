# Personal Resume

Personal Resume in JSONResume Format.

## Build

The layout lives in `theme/`, a customized copy of [jsonresume-theme-onepage-plus](https://github.com/vkcelik/jsonresume-theme-onepage-plus) tuned to fit on one US Letter page.

```shell
npm install
```

### Generate PDF

```shell
npm run build-pdf
```

### Generate HTML

```shell
npm run build-html
```

### Validate against the JSON Resume schema

```shell
npm run validate
```

### Live preview

```shell
npm run serve
```
